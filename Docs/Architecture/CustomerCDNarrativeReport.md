## 7. History branch

C2는 GetRecommendationForVisit(C,1), D2는 GetRecommendationForVisit(D,1)을 기존 ConfigureActiveNarrative가 조회한다. Narrative Definition의 MemoryVisitNumbers=[1], Best/Good/PoorIntroRows 각각 1행 + OrderedRows 4행. NO_MEMORY/unknown result는 추가 회상 없이 공통 현재 Beat 4행으로 진입한다. C1/D1 memory 목록은 비어 있고 오염된 현재 Visit1 기록도 회상으로 사용하지 않는다.

기존 GetActiveVisitMemory/OnRevisitMemoryReady와 CustomerID+VisitNumber idempotent Result 확정 저장을 유지한다. Narrative가 History 내부 배열을 순회하거나 점수/Result를 재계산하지 않는다. GOOD 회상으로 특정 mismatch 요소를 단정하지 않는다. BEST 및 D GOOD처럼 현재 LP로 도달할 수 없는 경로는 unsaved history fixture로만 테스트한다.
