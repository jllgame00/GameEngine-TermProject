# Map Policy

No maps are created by this scaffolding. Create the following levels later from Unreal Editor, using the naming convention below.

| Folder | Intended map |
| --- | --- |
| `Content/RecordShop/Maps/Main/` | `L_RecordShop_Main` |
| `Content/RecordShop/Maps/Greybox/` | `L_RecordShop_Greybox` |
| `Content/RecordShop/Maps/Test/` | `L_Test_Interaction`, `L_Test_NPC`, `L_Test_Dialogue`, `L_Test_Recommendation`, `L_Test_Turntable`, `L_Test_UI` |

Keep test maps separate so parallel feature work does not require several developers to edit the same binary `.umap`. `Maps/Lighting/` is reserved for lighting-focused work.
