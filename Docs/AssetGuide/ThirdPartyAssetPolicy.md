# Third-Party Asset Policy

`Content/ThirdParty/` is reserved only as a namespace for third-party assets that the team manually controls. No existing asset is moved into it by this setup.

- Preserve each vendor, Fab, Marketplace, and template asset pack in its original namespace because packs may rely on those paths and references.
- Copy an edited or derived game asset into the appropriate `Content/RecordShop/...` production folder.
- Never modify a vendor master asset when a local derivative is more appropriate.
