# Development Folder Policy

`Content/RecordShop/Dev/<Person>/` is each contributor's scratch workspace. Experimental assets belong there first.

Once an asset is verified and becomes part of the game, move it from Unreal Editor's Content Browser into the appropriate production folder. Never move a created or imported `.uasset` manually in Windows Explorer: use the Content Browser so references and redirectors are handled correctly.

Production folders contain reviewed game assets, not random tests.
